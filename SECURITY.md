# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.0   | :white_check_mark: |
| >1.0.0  | :x:                |

## Reporting a Vulnerability

To report a vulnerability, you can contact us in any of the following ways:


- GitHub (PREFERRED): [GHSA report](https://github.com/aetherra/stardust/security/advisories/new)
- Email: hi@aetherra.org
- Discord: DM `tg.t` or `thespritzer_`. Do NOT report it in the Discord server as it is public.

We'll update you via your original method of contact unless you state otherwise. If it is accepted, a patch will be pushed within 1-4 days, and an advisory will be posted to GHSA.
